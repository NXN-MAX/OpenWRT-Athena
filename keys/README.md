# Athena feed public keys

These are public verification keys for Athena's independent package feed. They
are not OpenWrt official signing keys. Private keys must never be placed here.

| Format | Public key | Identity |
| --- | --- | --- |
| opkg/usign | `athena-opkg.pub` | `efe004bab7c083b3` |
| APKv3/P-256 | `athena-apk.pub.pem` | SHA256 `6fc101f3c59dd1a98a1f3e172eb768f79e1298d1e09b9ec0bd34874b8aee3420` |

See [installation, verification and key rotation](../doc/signed-feed.md).
