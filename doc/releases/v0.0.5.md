## Athena v0.0.5

### 更新内容

- 修复 Safari 深色模式登录 SVG 背景的配色；默认背景使用页面外观控制的 SVG 遮罩，自定义图片与视频保持原有流程。
- 简化登录 SVG 曲线，从 1,090,168 字节压缩到 30,280 字节，减少约 97.2%；提前预加载默认背景。
- 主题更新检查仅使用正式 Release 附件 `athena-release.json`，不再依赖 GitHub API 配额，也没有分支或第三方镜像回退；清单校验版本、官方地址、大小和 SHA256。
- 发布流程自动生成更新清单；补充清单生成与错误处理测试。
- README 提供中、英、日、韩、法、德、阿拉伯七种语言和实际界面截图；样式维护规范移至 `doc/style-maintenance.md`，文档截图不进入设备更新归档。

### 安装与更新

- OpenWrt 24.10 / opkg：下载 `.ipk`（架构 `all`），上传到 `/tmp` 后执行 `opkg install /tmp/luci-theme-athena_*.ipk`。
- OpenWrt 25.12 / apk：下载 `.apk`（架构 `noarch`），执行 `apk add --allow-untrusted /tmp/luci-theme-athena-*.apk`。独立 SDK 构建的包不使用 OpenWrt 官方软件源签名。
- `.tar.gz` 供内置在线更新器及原生归档安装使用。通过内置更新器安装不会修改包管理器的版本记录。
- 先用 `SHA256SUMS` 核对下载文件；依赖由设备对应固件的软件源安装。保留 Athena 配置和上传素材。
- 设备运行验证环境为 OpenWrt 25.12.6 / armsr/armv8；24.10 SDK 构建通过不等于完成所有设备测试，23.05 暂未实测。

v0.0.4 保留供回滚。卸载前请先切换到其他已安装主题。

### Changes (English)

Fix Safari dark login artwork, reduce the default SVG from 1,090,168 to 30,280 bytes, and preload it. Use the official Release manifest as the sole update source, with archive size and SHA256 validation. Add seven-language documentation and actual screenshots without adding image payloads to the router update archive. Existing settings and uploaded branding are preserved.

Choose IPK for OpenWrt 24.10/opkg or APK for 25.12/apk. Verify `SHA256SUMS` before installation. APK builds are independent SDK packages, not signed by the official OpenWrt repository. Keep package formats and firmware feeds consistent.
