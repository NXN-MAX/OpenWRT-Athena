## Athena v0.0.6

- 浏览器标题仅显示 OpenWrt 原生系统主机名，移除固定的 `· Athena` 后缀和附加页面名；登录页与后台使用同一模板。
- 主机名继续通过“系统 → 系统 → 通用设置 → 主机名”管理，主题不新增重复配置。
- 包含 v0.0.5 的全部更新：30,280 字节压缩 SVG、Safari 深色登录背景修复、正式 Release 清单更新机制及七语言文档。

### 安装与更新

- OpenWrt 24.10 / opkg：使用 `.ipk`，执行 `opkg install /tmp/luci-theme-athena_*.ipk`。
- OpenWrt 25.12 / apk：使用 `.apk`，执行 `apk add --allow-untrusted /tmp/luci-theme-athena-*.apk`；独立 SDK 包不使用 OpenWrt 官方软件源签名。
- `.tar.gz` 供内置更新器使用；内置更新保留设置与上传素材，不修改包管理器版本记录。先核对 `SHA256SUMS`，依赖由设备对应固件的软件源安装。
- 实测环境为 OpenWrt 25.12.6 / armsr/armv8；24.10 SDK 构建不代表所有设备已实测，23.05 暂未实测。旧版 Release 保留供回滚。

### English

Use only the native OpenWrt hostname as the browser title, without a fixed theme suffix or page name. Login and administration share this behavior. Manage the hostname through the existing System settings. Includes all v0.0.5 fixes: compressed SVG, Safari dark login artwork, official Release manifest updates and multilingual documentation.

Install IPK on 24.10/opkg or APK on 25.12/apk. Verify SHA256SUMS and use matching firmware feeds. Existing settings and uploaded branding are preserved.
