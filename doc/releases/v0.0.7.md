# Athena v0.0.7

This release addresses feedback on [LuCI PR #9291](https://github.com/openwrt/luci/pull/9291).

- Background uploads are copied in 64 KiB chunks after a header check. The 20 MiB limit stays in place.
- Removing an active Athena package switches to an installed theme when available and removes Athena's uploaded branding. Package upgrades preserve uploaded files.
- The settings route is `/admin/system/athena`. Existing standalone links to `/admin/system/Athena-config` still work.
- The sidebar uses the OpenWrt spelling.

The [Athena signed feed](https://github.com/NXN-MAX/OpenWRT-Athena/blob/main/doc/signed-feed.md) provides verified installation and updates for OpenWrt 24.10 (opkg/IPK) and 25.12 (APK). The Release also includes standalone SDK packages, the native update archive, and checksums.
